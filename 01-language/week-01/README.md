# Неделя 1. Базовый синтаксис

**Время:** 5–7 часов
**Цель:** писать простые функции на Python не подглядывая в синтаксис

## Как работать

1. Открой `tasks.py` — там 12 функций с описанием и `raise NotImplementedError`.
2. Запусти тесты — они все красные. Это нормально, так и должно быть:
   ```bash
   uv run pytest 01-language/week-01 -v
   ```
3. Реализуй функции по одной, после каждой прогоняй тесты.
4. Одна задача — один коммит. Например: `feat(week-01): task 03 — подсчёт слов`.

Тесты — это спецификация. Если непонятно, что должна делать функция, читай
`test_tasks.py`: там видны конкретные входы и ожидаемые выходы.

## Грабли для фронтендера (записывай свои в `notes/`)

- **Отступы — синтаксис.** 4 пробела. Смешивать с табами нельзя.
- **Нет `let`/`const`.** Область видимости — функция, а не блок. Переменная из
  `for` живёт после цикла.
- **`==` сравнивает значения, `is` — идентичность объекта.** Для `None` всегда
  `is None`, не `== None`.
- **Изменяемый аргумент по умолчанию — классическая ловушка.**
  `def f(items=[])` создаёт список **один раз**, при определении функции, а не при
  каждом вызове. Правильно: `def f(items=None)` и внутри `items = items or []`.
- **Нет `undefined`.** Есть только `None`.
- **Ложные значения:** `0`, `""`, `[]`, `{}`, `set()`, `None`, `False`. Пустой
  список ложный — в JS был бы истинным.
- **Срезы не бросают ошибок.** `[1,2,3][10:]` — это `[]`, а не исключение.
- **Строки неизменяемы**, как и в JS, но методы называются иначе:
  `.upper()`, `.strip()`, `.split()`, `.join()`.
